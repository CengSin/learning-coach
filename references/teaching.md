# 备课、教学与实际计时

备课、讲解与批改同时遵循 [accuracy.md](accuracy.md) 的事实依据、类比边界、证据资格和复核规则。

## 开课前

读取项目配置、当前进度、最近场次、最新学习记录和本次涉及资料的目录。状态已结束时，新用户请求才开新场；状态进行中或暂停时恢复原场，不重新获得完整预算。维护资料、制定计划和测试脚本均不自动开课。

从当前证据生成小纲，列明：接续位置、可检验的能力目标、教材页段和核验状态、少量混合复习、核心与贯穿例子、独立练习、相关综合、备用深化及收尾。小纲是计划，实际结果另记。核心和备用任务属于同一主线，答得快进入备用任务，需要订正就顺延扩展。

小纲另列“本次关键事实”和“关联既有知识”，使用 accuracy.md 的精简字段。未核对事实在开课前先尝试查资料；无法核对则课堂明确标记。先讲新旧知识的对应关系，再说明类比不成立之处，避免把联想当等价。

正式发题前读取时钟工具；以同一真实时间启动场次，记录时区、起点、预算、截止和分段范围。脚本使用系统时钟实际读时，不接受任意历史起点参数。发现工具时钟与系统时钟明显不一致时说明计时未确认，先查明差异，不补造时间。教学回复前运行 `session_clock.py --root . tick`，结合返回的已用、剩余和阶段决定内容。

给用户一两句衔接和整场安排。先用通常 2～4 道混合题，必要时到 5 道，复查上次重点；只补暴露的错点，正确后及时推进。

## 一个小段

采用“必要概念 → 一个完整例子 → 2～4 道独立诊断 → 针对错点订正”。复杂新知识拆段；不让固定题数覆盖真实剩余时间。先解释中文术语、符号角色和适用范围，说明本段输出怎样成为下一段输入。

练习从单步或两种情况对照，逐渐到相关边界、短综合和改变已学条件的迁移。沿用贯穿例子或明确新输入，不为每个小点另开一组长练习。关键条件放在计算前：范围、初值、位数、编码类型、独立／连续、简化模型和结果去向。要求能定位错误的短过程，避免无关抄写。

不提前公布独立练习答案。用户要求提示时逐级提供，并将提示依赖写入证据；最终答对不自动变为无提示独立正确。

## 批改与调整

给出判错结论前二次核对答案依据；用户步骤合理而答案不同则先复算。只在写入错题或合理分歧时记录复核结果，具体条件见 accuracy.md。

- 先指出具体正确的步骤和理由，定位最早错误环节；保留后面仍成立的方向。概念、算术、抄写、遗漏、条件混用分别处理。
- 只有结果时不推断错误步骤。展开必要路径或给一个小对照，让用户确认。
- 答案在另一种条件成立时，列出本题与另一条件的差异，只修改错误的起点、范围或假设。
- 同点再错时减少同时处理的变量，改用位置图、比较表或最小例子；确认后用少量新输入回到短综合，不无限重复原题。
- 用户自责或自述跳读时，以当前作答为依据，给出计算前可执行的动作；不作能力、人格或诊断性评价。
- 用户说难时缩小当前目标，把扩展移后；疲惫、有事或要求停止时按真实时间提前收尾并记原因。

## 时间政策

读取课程的 `time_policy`，不在通用 skill 中固定每天时长。工作日、周末总预算、周末分段和当次可用时间分别处理。默认新概念截止点为本段结束前 10 分钟，新独立题截止点为结束前 5 分钟；具体值由项目配置。开场需满足 `0 ≤ 新题窗口 < 新概念窗口 < 本场预算`；短课先给出适合本场的窗口，用 `start --concept-window-minutes ... --question-window-minutes ...` 保存，不修改整门课的默认值。例如8分钟课可设3／1分钟窗口；纯复习用 `--review-only`，允许直接进入巩固或总结。窗口与阶段随核时结果显示，不能悄悄将短课当作已收尾。

60 分钟项目可用 0～10 复习、10～30 概念例子、30～45 练习订正、45～55 综合迁移、55～60 总结。每轮核时；在配置检查点、调整范围和收尾时简短告知，不要求每次重复同一句计时说明。

读题、思考、作答、批改和课堂等待均计入。只有用户明确暂停才用 `pause --reason ...`，恢复用 `resume`，截止随已确认暂停调整。“继续”不增加预算。具体加课必须有用户明确授权的时长，再用 `extend --minutes ... --reason ...` 记录。首次开课与加时都核算整日累计；加时包含已归档时长及当前场次完整预算，已超时则至少计实际已用。当前脚本按场次开始日归档，加时沿用该日。

超过原日预算或同日另有未知时长时，普通 `--reason` 不覆盖预算检查；已有用户明确的本次时长安排，才加 `--override-daily-budget --reason ...`。上下文已有明确授权无需重复询问。脚本保留本次分钟数、已知累计、未知标记、超额秒数和原因；该标记记录 Agent 的授权依据，不是脚本对自然语言授权的判断。未知部分不能当零，也不能让已确认累计消失。

全量解析扫描、整本资料指纹和全库链接校验尽量在正式启动前或结束后执行。进行中接续先核时并复用本段缓存，必要的轻量检查可用 `validate.py --quick`；它不宣称完成全文检查。维护不会另开场，但在运行场次内花费的墙钟时间仍计入，不能事后任意扣除或自行暂停。

已过新概念截止只收束当前题与已学连接；已过新题截止进入总结；达到截止不再教学。收到消息已经超时，照实记录超时并收尾，不能伪记恰好预算时长。明显提前结束前检查备用综合是否遗漏，禁止靠重复简单题或等待凑时长。

## 收尾与接续

每个教学单元收尾安排一次几分钟的闭卷复述，对照关键事实清单，只持久记录遗漏或错误。复述提前计入预算，不挤占独立练习；时间不足顺延，不在截止后加题。AI 讲解本身不计掌握证据。

明确说“今天可以结束了”或“今天先到这里”。给实际用时、完成目标、仍需检查的点和下一次入口，用简短流程或审题卡连接本次内容，可请用户用一句话留下提醒，不加新题。分别记录目标完成、时长和延迟保持。

小段结束、重要订正、安排变化、日终更新真实证据，日终结束计时并生成当前视图。独立每日 HTML 根据课程保存约定执行；用户要求保存即执行，不再次询问。课后整理不增加课堂时间。周末分段结束与整日结束分清，保留已用总预算。

课后保留未核对事实，汇报带分母的自编题占比；历史证据加新规未核验标注，现有复习安排照常保留。
