# 验证与真实课程试用

## 先验证确定性行为

执行 `python3 <skill>/scripts/test_workflow.py`，在独立临时目录测试计时状态机、首次／累计日预算与加时、失败不落盘、暂停恢复、重复启动保护、实际超时、短课窗口、未知时长下界、跨日证据与当天迁移、旧摘要迁移、复盘日期顺延、生成时快照、原稿断链分级、轻量检查范围、解析目录变更发现和 skill 移动后的命令／模板定位。测试输入是夹具，不写入真实课程。

创建或重要修改后，执行 skill-creator 的 quick_validate.py 检查 skill 本身；运行 validate.py 检查项目。只有语法检查通过不能证明教学效果。

## 用真实证据回放

从最近真实记录读取用户请求与原始证据，检查以下可观察行为，报告依据和结果，不新增学习记录：

| 场景 | 应观察的行为 |
|---|---|
| 已结束的课后要求整理／创建 skill | 不重启计时、不增加学习天数或掌握程度 |
| 进行中换对话并说继续 | 原起点不变，读取真实剩余时间 |
| 默认10／5窗口，剩余8分钟 | 只订正和连接当前内容，不引入新概念 |
| 进入本场新题截止窗口 | 总结，不新增独立题 |
| 收到回复已经超过截止 | 如实记录超时并收尾 |
| 历史错点已有后续正确证据 | 显示最新结论，旧原答只在历史中保留 |
| 当场订正但未隔日验证 | 作答保留当场订正，复查安排为待隔日检查；不能标隔日正确 |
| 同天改变输入或条件后独立正确 | 可记录迁移正确，不冒充隔日保持 |
| 只读 PDF 目录 | 记录目录已核验、正文未读；不声称全文核验 |
| 用户选择自行解析 | 实际创建每份资料的存放目录，告知绝对路径和保留图片层级的要求 |
| 未专门通知就开始下一次学习 | 主动扫描解析根目录与登记目录，发现新增或变更后接入；不依赖聊天记忆 |
| skill 移到新目录 | 从实际脚本位置定位模板和维护命令，首页使用课程配置中的skill路径 |
| 用户说解析结果已放好 | 读取实际文件、检查正文和素材、生成导入索引；不要求手填元数据或重新 OCR |
| 已有解析但页码映射不明 | 可靠章节可先接入，页码标待定位；不把导入完成记为全文核验或已学 |
| 付费启动算力且计划处理整批课程资料 | 先提交范围、估算、费用上限和释放安排；同次部署内样页验收后连续分批处理 |
| 批量提取已经完成 | 逐页覆盖可追溯；未核验正文与用户未学状态保留，课堂不再次启动算力 |
| 批量中断或部分失败 | 从落盘清单续跑，仅补失败、缺页或低质页；不重新 OCR 成功页 |
| 结果只在临时云盘，或释放状态未知 | 不报告已交付或已停止计费；按实际状态处理输出与资源 |
| 公式或图表不能可靠识别 | 告知具体资料和页范围，不据猜测判错 |
| 题集入口存在但正文尚未取得 | 只计来源入口，不计题目已收录 |

## 真实试用

下一次用户实际开课后，使用小纲和计时完整执行；观察开场接续、条件说明、批改归因、难度调整、时间边界、收尾与落地。记录用户具体反馈和实际偏差。模块掌握与目标完成仍依据作答，不能用“skill 检查通过”替代。

如使用独立评估，只给评估者 skill、真实请求和必要原始材料，不透露预期答案或已发现的问题；输出放临时目录，不能影响真实课程。没有做独立评估时如实说明。
