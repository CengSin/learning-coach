# 验证与真实课程试用

## 先验证确定性行为

执行 `python3 <skill>/scripts/test_workflow.py`，在独立临时目录测试计时状态机、首次／累计日预算与加时、失败不落盘、暂停恢复、重复启动保护、实际超时、短课窗口、未知时长下界、跨日证据与当天迁移、旧摘要迁移、复盘日期顺延、生成时快照、原稿断链分级、轻量检查范围、解析目录变更发现和 skill 移动后的命令／模板定位。另覆盖：课中记账日志的必填校验（自编题复算、错题复核）和 commit 幂等；核时返回 next_action；预算未用完时拒绝无 `--user-stop` 的收尾；每日记录页的目录、锚点、错题汇总和防覆盖。测试输入是夹具，不写入真实课程。

计时模式覆盖：默认窗口行为不变；deadline 支持短课，剩余1秒仍在教学、到点及超时进入收尾；课程默认模式与本场覆盖可用且不能中途改变；旧极短窗口场次不迁移、不受后来配置覆盖。deadline 本场窗口为0／0，拒绝显式非零窗口与无效模式；纯复习仍可提前完成。普通课堂在总结窗口也不得无授权提前结束。临时项目完整运行生成与 validate.py，确认模式可以保存、归档，记账提供精确秒数。

创建或重要修改后，执行 skill-creator 的 quick_validate.py 检查 skill 本身；运行 validate.py 检查项目。只有语法检查通过不能证明教学效果。

教学校验测试覆盖：精简事实字段与依据等级、知识关联边界、独立复算方法及一致结果、教材解析正文依据可用且仍须有来源位置、待核对或不一致的解析核验不取得掌握资格、新自编练习不冒充掌握、普通批改不强制复核记录而新错题与合理分歧必须记录、闭卷复述仅记遗漏／错误、掌握依据去重及空样本、历史标注与复习队列／到期安排不变。使用通用夹具，不写入具体学科知识。

规划校验覆盖：新项目在缺目标或期限时明确标待规划；已启用计划的阶段、模块有有效时间窗，每个计划日有预算、主线和成果；缺日、重复日期和超出截止范围应报错。重排后检查旧计划留存、下次小纲与当日简纲一致、页面显示当前模块相对截止的偏差，旧学习证据和计时不因重排改变。

教学深度校验覆盖：旧项目无策略仍兼容；启用后须有大纲动词/对象/出处与非同名映射理由；默认额度覆盖须有取舍依据；子主题合计不超过父预算；同主题拆成多项仍合计讲练与分钟、此前已投只加一次；前轮与后续额度分开、了解级复查须有理由；所选内容与衔接合计不超过本次窗口。畸形字段、负数、布尔值冒充数字和非有限数须拒绝。用临时项目验证渲染及完整校验，不改真实课程来满足新字段。

兼容日期边界也须覆盖：项目中最早出现 assessment 的日期之后，缺少 assessment 的作答事件和错题视为漏填，校验给 MISSING_ASSESSMENT 警告，须依据实际作答补写 assessment，不计入历史；该日期当天及更早的缺失记录仍按历史处理；讲解事件不要求 assessment；项目中尚无带 assessment 的记录时不触发该警告。

新增阅读内容只在临时项目生成后完整运行 validate.py。真实项目只读校验，不重建课程文件；因技能与渲染变更产生的视图过期单独报告，不用跳过检查冒充全部通过。前后核对技能目录以外文件的指纹。脚本只能验证结构、关联和资格，不能证明内容正确或用户真实闭卷。

## 用真实证据回放

从最近真实记录读取用户请求与原始证据，检查以下可观察行为，报告依据和结果，不新增学习记录：

| 场景 | 应观察的行为 |
|---|---|
| 已结束的课后要求整理／创建 skill | 不重启计时、不增加学习天数或掌握程度 |
| 暂停中要求维护或讨论skill | 保持暂停，时间与真实作答不变 |
| 了解级主题已有一次练习且订正后仍不稳 | 保留实际缺口，停止加练；不靠更小变式或闭卷复述刷新题量 |
| 拆分复杂主题、换对话或换学习日 | 同主题同阶段累计原投入，受父级总预算约束 |
| 大纲低层级但教材细节复杂 | 深度跟随对象的具体要求，不因复杂升级，不假定固定分值 |
| 进行中换对话并说继续 | 原起点不变，读取真实剩余时间 |
| 用户答对且当前主题结束，仍有教学时间 | 简短反馈后在同轮连接下一项，无须用户说“继续” |
| 常规新授课已短查旧错，另一个主题还有到期原题 | 对照整场回顾预算和下一步前置，够用即直接讲新单元，保留其他复查；专门复盘仍按原预算执行 |
| 用户插问且问题已解决 | 回到被打断主线，说明与下一步的关系，不在答疑末尾悬空结束 |
| 本主题题量或时间额度用尽 | 保留缺口并转出，不追加确认题，也不交回没有待答事项的话轮 |
| 临近截止且放不下新单元 | 用已学关系、关键条件或下次问题定位完成有意义的教学，不塞零散新概念或凑题 |
| 到点后用户要求保存HTML | 先明确结束并连接本次内容、交代待验证项和下次入口，再归档交付；文件完成通知不能替代课堂收尾 |
| 默认10／5窗口，剩余8分钟 | 只订正和连接当前内容，不引入新概念 |
| 进入本场新题截止窗口 | 总结，不新增独立题 |
| 收到回复已经超过截止 | 如实记录超时并收尾 |
| 历史错点已有后续正确证据 | 显示最新结论，旧原答只在历史中保留 |
| 当场订正但未隔日验证 | 作答保留当场订正，复查安排为待隔日检查；不能标隔日正确 |
| 同天改变输入或条件后独立正确 | 可记录迁移正确，不冒充隔日保持 |
| 只读 PDF 目录 | 记录目录已核验、正文未读；不声称全文核验 |
| 用户选择自行解析 | 实际创建每份资料的存放目录，告知绝对路径和保留图片层级的要求 |
| 未专门通知就开始下一次学习 | 主动扫描解析根目录与登记目录，发现新增或变更后接入；不依赖聊天记忆 |
| skill 移到新目录 | 从实际脚本位置定位模板和维护命令，首页使用课程配置中的skill路径 |
| 用户说解析结果已放好 | 读取实际文件、检查正文和素材、生成导入索引；不要求手填元数据或重新 OCR |
| 已有解析但页码映射不明 | 可靠章节可先接入，页码标待定位；不把导入完成记为全文核验或已学 |
| Markdown 正文和公式清晰完整 | 直接使用相关段落，依据记解析正文；不为取得原页标签额外打开 PDF |
| 当前段落有乱码、歧义或依赖缺失图表 | 只为该疑点核对最小局部图／页段，不因其他章节缺图读取整章 |
| 同一内容已有核验且来源未变 | 复用已保存的文字结论，不在每轮重复看图 |
| 委派 subagent 处理多页复杂图表 | 限定路径、页段和疑点，先查正文；回传带出处的文字与未决项，不把整批图片回灌主线程 |
| 付费启动算力且计划处理整批课程资料 | 先提交范围、估算、费用上限和释放安排；同次部署内样页验收后连续分批处理 |
| 批量提取已经完成 | 逐页覆盖可追溯；未核验正文与用户未学状态保留，课堂不再次启动算力 |
| 批量中断或部分失败 | 从落盘清单续跑，仅补失败、缺页或低质页；不重新 OCR 成功页 |
| 结果只在临时云盘，或释放状态未知 | 不报告已交付或已停止计费；按实际状态处理输出与资源 |
| 公式或图表不能可靠识别 | 告知具体资料和页范围，不据猜测判错 |
| 题集入口存在但正文尚未取得 | 只计来源入口，不计题目已收录 |

## 真实试用

下一次用户实际开课后，使用小纲和计时完整执行；观察开场接续、条件说明、批改归因、难度调整、时间边界、收尾与落地。记录用户具体反馈和实际偏差。模块掌握与目标完成仍依据作答，不能用“skill 检查通过”替代。

回放时区分原回复实际表现与新规则要求；不能把重写示例当成新规则已经有效的证据。记录无待答任务却结束回复、用户被迫说“继续”及缺失课堂收尾的具体位置，下一场再观察是否改善。

如使用独立评估，只给评估者 skill、真实请求和必要原始材料，不透露预期答案或已发现的问题；输出放临时目录，不能影响真实课程。没有做独立评估时如实说明。
