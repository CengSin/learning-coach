# 资料、PDF 与题目质量

事实依据分级、关键事实清单、自编题独立复算及批改复核统一见 [accuracy.md](accuracy.md)，按其规则登记和使用资料。

## 从目标建立资料索引

目标缺失时先询问目标；已有课程复用已知信息。需要时补问基础、期限和预算。按目标检索官方课程／考试范围、出版社书目和其他一手资料，记录资料名、版本、正规获取入口与核查日期，不把搜索摘要当已读正文。

创建项目内 materials，展示实际绝对路径。已有资料直接登记，不要求搬两遍。官方范围确定覆盖边界，教材提供解释和章节依据；自主学习根据目标与资料生成范围。目录仅支持初版规划，不表示已核实全书。

catalogue.json 每份资料记录 id、相对路径、书名、版本、SHA-256、总页数、目录页范围、目录条目、页码映射状态、已读页段、待核对项。PDF 页序从 1 开始，书内页码单独保存；前言、插页和附录可能改变偏移，未抽查不能宣称整本固定偏移。

## 用户自行解析 PDF

1. 为已登记的每份资料创建 `materials/parsed/<资料ID>/`，在 catalogue.sources[].parsed.directory 登记，并向用户给出该目录的实际绝对路径。每份 PDF 一个子目录，标明对应资料名；原 PDF 保留原位置。新项目初始化创建 `materials/parsed/`，资料登记时再建立具体子目录。
2. 告知用户把工具导出的完整文件夹放入该目录，保留 Markdown、TXT、HTML、JSON 等正文文件及其引用的图片／表格素材和相对层级。无需统一改名或手填 JSON；能附原 PDF 文件名、工具名及页码说明即可，缺失信息由 Agent 检查后补齐，不能据此阻止读取已有结果。
3. 在尚未开课的接续、备课及启动新 OCR 前，运行 `python3 <skill目录>/scripts/scan_materials.py --root <项目目录>`。用户无需专门通知；用户说“放好了”“读取解析结果”时也检查。已有运行场次时先核时并复用本段既有索引，仅检查当前确实要使用的资料；全量扫描、导入和链接校验放收尾后，发现当前材料失效则停止使用并说明，不自行暂停或扣除墙钟时间。扫描同时覆盖 materials/parsed 根目录、其未登记子目录和 catalogue 指定目录，按内容指纹比较导入清单；只读报告新增、变更、缺失和未归属文件，Agent 再按需增量导入并更新索引。用户直接放在根目录或自命名文件夹时先识别归属，能确认则登记原位置，不强制搬动；无法判断时再询问。已变更文件的旧行号、页码和核验结果先标待复核，不能沿用过期索引。先识别入口正文、配套素材、目录和页码标记，再按当前任务读取相关章节，避免整本全文一次塞进上下文。原稿辅助断链由 validate.py 分级报告，Agent 将问题记入导入 issues；缺失必要图片或影响题干、公式、答案依据时，将对应范围标 needs_review 并暂停用于判题。目录为空则标待放入，不能假称已导入；没有后台监听能力，不承诺文件放入后无人值守自动处理。
4. 保留用户导出文件，不覆盖。Agent 生成 import-manifest.json，记录文件指纹、来源资料、正文入口、素材引用、章节索引、PDF 页序映射与缺失项。抽查正文可读性、图片链接和关键公式；页码无法确定时标待定位，必要时只询问确实无法判断的来源信息。不要求用户先修成指定格式，能可靠读取的部分先接入。
5. 更新 catalogue 的导入状态、索引与阅读页。后续备课与教学优先读取已导入章节，按原页核验；仅对实际缺口安排补处理。用户提供了解析结果不表示全文已核验或已经学习，也不触发重新 OCR。新文件按指纹重新检查，未变化的结果复用；状态字段与映射约定见 [state.md](state.md)。

## 按成本提取，按章节教学

先读封面／版权页和目录，建立初版大纲；再决定正文的提取方式。目录初始化不必等整本 OCR 完成。区分三件事：机器提取、教学内容核验、用户学习证据，三者分别记录。

| 资料／服务情况 | 默认选择 |
|---|---|
| 已有可用文本层或用户提供的解析文件 | 优先本地提取／导入，抽查阅读顺序和公式；仅对有缺口的页面补 OCR |
| 需专门付费启动 GPU，存在启动开销或最低计费 | 优先一次部署：样页通过后连续分批解析本课程选定的 PDF，保存到本地，再释放算力 |
| 按页／按量收费接口、已有常驻服务或可用免费环境 | 比较预期总价、覆盖范围和耗时，再选整批或按需；不为此另开一台常驻机器 |
| 已有完整且可追溯的解析缓存 | 教学直接读取章节缓存；缺页、低质页或版本变化时才补处理 |

“全部”仅指用户选定并登记的本课程资料。按文件指纹去重，排除无关文件、已有合格解析和不需要 OCR 的页。新增资料另建增量任务，不重复跑旧资料。Unlimited-OCR 是候选后端，不是 skill 的强制依赖；可导入其他工具的结果，但必须保留页序和来源。

### 一次部署的批量任务

1. **付费前准备清单。** 列明来源 ID／SHA-256／页数、已有缓存、预计新增处理范围、后端与模型版本、运行参数、计费方式、费用上限、超时／重试上限、输出位置和释放方式。按模板给出可审阅任务。费用依据具体服务和小样吞吐估算，注明误差；模型开源不等于算力免费。未配置服务和预算时仅完成计划，不启动收费资源。
2. **样页验收后在同一次部署中继续。** 默认选约 3～5 页，覆盖目录或多栏、普通正文、公式／上下标、复杂表格和图；可合并选页，按实际版式补样。逐页对照，检查遗漏、错序和关键符号。将小样与后续整批纳入同一费用授权，验收通过后直接推进，不为每个章节重复部署。质量不合格时中止整批并按事先约定停止计费；不要让机器空闲等待下一堂课。
3. **整批任务，有限页段执行。** 逐页或小批连续处理，限制并发、显存、输出长度和临时磁盘占用。批大小依据样页与后端限制调整；不是把整本教材一次塞入模型上下文。`pdf_pages.py --root . --source <资料ID> --pages <起页-止页>` 只准备其中一批，默认最多 12 页；这不是任务总页数上限，也不是模型推荐批大小。
4. **逐页落盘与断点续跑。** 每个成功页立即保存。任务清单以来源指纹、后端／模型版本、影响结果的参数和 PDF 页序定位输出；页状态为 pending／running／extracted／failed／needs_review，核验状态另列。中断后核对输出存在性和指纹，只补缺页、失败或明确低质页，保留旧结果。换版本不悄悄覆盖，重新出清单比较是否值得重跑。
5. **交付完整性检查。** 核对预期页数与逐页状态；检查空结果、截断、重复页、错序、缺图和跨页断裂。真正空白页也要对照原页确认。保存 Markdown／结构化结果、图表素材、页序映射、失败清单和任务日志。原 PDF 保留为页面依据；不要求为全书永久保留可重建的大尺寸页图，但要保存无法从文字还原的图表素材。
6. **先保存结果，再结束租用。** 输出必须复制到项目可持久保存的位置，核对文件和清单后，按任务约定释放专用算力，记录起止、实际费用或“账单待确认”。异常与预算触顶也执行保存检查点和停止流程。停止进程、关机与终止计费可能不同，按服务核对计算、存储等剩余费用；不关闭共享服务或其他任务的机器。没有实际执行释放就不能报告“已停止计费”，也不把 Agent 会话当成有后台守护能力的作业系统。

现有页段脚本不包含 OCR 调度、付费部署、自动重试或资源释放。上述是 Agent 接入具体后端时必须执行的约定，未接入时如实标明，不能声称已具备自动托管服务。

估算比较的是总成本：部署／模型加载、样页、正文处理、重试与空闲的计费时间，加上适用的接口、存储和传输费用。集中解析能减少反复启动开销；资料很大而只学少量章节时，未必比按量处理便宜，不作没有报价依据的承诺。

### 课堂读取与知识核验

按本次小纲读取相关连续页段的本地结果，带上跨页公式、表格或例题所需上下文；没有缓存时说明当前能否本地读取，付费补处理另按任务预算执行。目录推算的正文范围先标待定位，进入章节时确认 PDF 页序；全文 OCR 不能自动证明书内页码映射正确。

对照原页检查负号、指数、上下标、位宽、公式边界、表头、合并单元格与图中箭头／连线。图中文字和图的含义分别验证。批量验收只确认覆盖与抽样质量；未核对的正文仍为“已提取、未核验”，不因此增加已学内容。

局部不清时可放大再核对；仍不能确认则列出资料名、PDF 页序范围、已确认的书内页码、公式／图表编号和待查内容，请用户查原 PDF。受影响知识与题目标待核对，暂不作为判错依据。低质页可集中加入后续修复任务，不在每堂课临时重启 GPU。

可用时复用 PDF 工具或 PDF skill；缺少依赖时明确具体缺项。工具缺失不是已经完成 OCR 的证据。

## Unlimited-OCR 优先候选

截至 2026-10-16 核查的依据：[官方项目](https://github.com/baidu/Unlimited-OCR)、[推理代码](https://github.com/baidu/Unlimited-OCR/blob/main/infer.py)、[公式和表格评测](https://arxiv.org/html/2606.23050v1#S5)。部署前复核当前官方说明。

检查是否已有可用本地环境或用户配置的服务。官方示例面向 NVIDIA／CUDA；不能据此宣称任意 macOS 可直接运行。未配置时标为未实测，不自动安装大模型或将教材上传外部服务。

正式接入先做上述样页验收，记录失败类型及原页对照，不能仅用模型自报置信度或论文总体分数通过本教材验收。官方提供 PDF、单页和多页图片入口；按成本策略选择整批任务或页段任务，使用逐页落盘的有限批次并保持原 PDF 页序。检查实际输出长度限制和失败返回；不能因为名称含“Unlimited”就假设整本可无损单次输出。

学习 skill 定义工作流与质量门槛，OCR 后端可替换。没有可用 OCR 时可核验可读页面；无法可靠读取的地方按上节告知页码，不编造内容。

## 题目发现、收录和答案核验

Agent 在初始化、周期备课或资料缺口出现时主动寻找题源，按需收录允许使用的公开样题和试题；用户选择并提供购买或账号授权取得的资料。实际课堂优先用已准备的题，不让搜集和大规模解析挤占教学。

题目记录 id、来源类别（官方公开／出版社整理／回忆／模拟／自编）、年份和批次（无法确认填未知）、来源位置、知识点、题型、题干图表完整性、答案来源、核验状态、是否改编，以及展示／提示／作答历史。搜索到一个题集入口不等于已取得题目正文。

收录前检查题干、选项、图表和答案，计算题重新求解，必要时用工具复算；主观题允许等价正确答案。只有 AI 自己产生的解析不能标为官方答案。争议或残缺题先标待核对，不用于判定掌握。诊断与阶段测试保留部分未见过题，重复题得分单独说明。

优先使用可用且已核验的真题或官方答案，无真题依据时明确告知。自编及改变答案相关条件的改编题，只有 independent_check 记录了独立方法且结果一致，才能作为新掌握或判错依据；未满足时仅作练习。题源身份、答案来源和复算记录分别保存，不从旧 verification 自由文本推定已通过新规则。

自编诊断题紧扣本次目标，先内部完整求解，再给用户题面；显式写关键条件和模型范围。不要把练习约定推广为通则，也不把教材中的历史政策当当前政策。考试、报名和政策信息使用时重新核实官方来源，不能据旧计划承诺日期或规则。

## 教学纠错回溯

发现教师讲解、参考答案或题目错误时，先明确更正和适用边界，保留原错误与更正日期，检查受影响的练习、错题和掌握结论。由错误依据产生的判错撤回，真实作答原文保留；新核验结果更新当前状态，历史快照标明已被替代。
